# v0.3.3 候选版本

本版本汇总 v0.3.2 之后的本地修复与 Windows/真实 DeepSeek 验证。定位为可继续开发和体验的候选版本，不能据此宣布全量验收通过、数学推导可靠或 PPT 制作能力已验证。

## 改动

- 保存：规范化自由笔迹恢复时的临时 checkpoint，保留旧草稿存储语义，避免仅打开草图就改变 revision、使建议和视觉引用过期。
- 重点协作：设置重点后，Agent 默认读取和显式全图读取都限定到重点及必要绑定文字；过期重点拒绝读取，缺少重点图片不回退整图，批注锚点拒绝越界。需要全图时由用户清除重点。
- 几何结构：line/arrow 返回最多 32 个有符号局部点及截断标记；未旋转时提供精确 scenePoints，旋转时明确不可直接换算。自由笔迹完整路径和任意自定义元数据不随结构请求发送。
- 分析：原生菜单支持图片与结构、仅图片、仅结构；纯结构跳过 PNG 导出和附件注册，不要求路线提供视觉能力。
- 界面：按实际聊天容器宽度切换画板布局；针对锁定 DSH grid 临时限制整层横向滚动，关闭后恢复原样式。
- 解释边界：明确区分已画事实、用途与推测，几何外观不是题目条件。实测仍有数学错误，提示约束不构成正确性保证。

没有升级依赖、迁移存储格式或更改公开 RPC 协议版本。继续复用 Excalidraw 0.18.1 和现有许可声明；不把复用画布计为原创能力。

## 保留的限制

- 原生 DS 自主数学解释 A02 仍失败；有正确核心结果也可能附带错误推导。
- 前端生成案例仍有焦点逃出弹窗、辅助文字对比度不足和项目行意外筛选，不能当作生产级网页，也不证明比纯文字更有效。
- OS DPI、其他平台/宿主版本、其他插件共存、真实无视觉路线、真实 429/超时等尚有环境缺口；P01 导出复测仍不完整，宿主全部资源释放未独立证明。
- 重点限制适用于本插件读取与批注锚点，不能清除聊天历史/附件或限制其他宿主工具，也不是全局修改权限沙箱。

版本合并不等同于发布 npm 包、完成比赛提交或宣布以上缺口关闭。
