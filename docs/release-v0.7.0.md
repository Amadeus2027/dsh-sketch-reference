# v0.7.0 — Sketch Graph

将已合并的 Sketch Graph 与性能修复整理为正式发行版。保留现有手绘参考板风格、右侧分屏、根草图存储与用户确认机制。

- React Flow 总览：独立草图节点、命名、用途、位置、缩放、普通连线、轻量 PNG 预览。
- 元素／多元素／虚拟框选区域锚点；页面跳转与细节展开有独立含义。细节单父级且禁止循环，页面导航允许循环。
- 双击进入唯一 Excalidraw 编辑器，细节面包屑、定位来源、删除锚点提示和手动重新绑定。
- 新存储域保存图和子文档；旧根草图保持原键。图与每张草图分别 CAS，连续布局操作合并写入；未确认写入及后续状态按标签页保留，核对 mutationId 后清理。
- 全工作流可编辑 JSON 备份、添加式恢复及中断重试。大型恢复任务先写 IndexedDB，事务失败或追加容量不足时不开始恢复；不覆盖现有根草图。只有实际删除节点才清理相关记录，失败后补偿重试；历史附件字节不做垃圾回收。
- `sketch_graph_read` 分页读取摘要，`sketch_read` / `sketch_read_image` 可指定 nodeId；返回可直接复制的图片读取参数。图片按需加载。
- 画板全屏与原生悬浮对话，拖动、键盘移动、收起、调整大小；同一聊天和 iframe 保留，退出恢复分屏。

常用入口只有总览／编辑、创建和按需展开的关联；设置随选中对象出现，备份恢复放在更多菜单。

边界：最多 100 个节点／300 条边；不提供自动布局、协作、可执行逻辑或 Agent 多节点写入。聊天批注、改图提案和原生附件发送保留在根草图。子节点用途标签与边语义都提供给 Agent，冲突描述仍可能需要用户澄清。根草图选区重点不会因新增图读取而被绕过。

## 本版稳定性改进

- 合法大图不再误用普通 16 KiB RPC 限制；100 节点／300 连线可以保存。
- 连续布局采用 500ms 本地检查点，手势结束／导航补记；保留单请求串行、CAS、恢复副本及坐标校验。
- 总览按版本缓存缩略图，返回时一次小请求核对版本，只有变化文档重新读取和导出；关闭工作区释放资源。
- 细节关联排除根节点，短框选可以重试，待保存文案与已保存状态明确区分。

## 安装与升级

下载本次 Release 的 `.tgz` 和 `SHA256SUMS.txt`，或解压安装 ZIP。保存、备份并退出宿主后：

```sh
dsh plugin --profile web add /绝对路径/dsh-sketch-reference-0.7.0.tgz
dsh web
```

无需单独安装 Excalidraw；继续使用 DSH 已配置模型。源码 ZIP → 构建 → 官方管理器添加目录的方式完整保留，见 [安装指南](installation.md)。升级保留原 profile、存储与浏览器数据，不删除旧根草图。

## 验证范围与限制

运行代码基线为 PR #35 合并后的 `80fa495`；正式化仅调整版本与发行文档，不改运行源码。其 TypeScript、25 文件／233 项单测、构建与两版官方 DSH Web 实装、真正重启、恢复、导出和附件回归已通过；具体包身份和原始数据见 [专项记录](review-graph-performance-20261017.md)。正式包另按 [发布核对](https://github.com/Amadeus2027/dsh-sketch-reference/blob/v0.7.0/docs/release-checklist-v0.7.0.md) 验证。
