# v0.7.0-alpha.1 — Sketch Graph

开发预览，尚未发布正式 v0.7.0。保留现有手绘参考板风格、右侧分屏、根草图存储与用户确认机制。

- React Flow 总览：独立草图节点、命名、用途、位置、缩放、普通连线、轻量 PNG 预览。
- 元素／多元素／虚拟框选区域锚点；页面跳转与细节展开有独立含义。细节单父级且禁止循环，页面导航允许循环。
- 双击进入唯一 Excalidraw 编辑器，细节面包屑、定位来源、删除锚点提示和手动重新绑定。
- 新存储域保存图和子文档；旧根草图保持原键。图与每张草图分别 CAS，未确认写入保留本地恢复副本。
- 全工作流可编辑 JSON 备份、添加式恢复及中断重试。删除节点会清理子文档和相关记录，历史附件字节不做垃圾回收。
- `sketch_graph_read` 分页读取摘要，`sketch_read` / `sketch_read_image` 可指定 nodeId；返回可直接复制的图片读取参数。图片按需加载。
- 画板全屏与原生悬浮对话，拖动、键盘移动、收起、调整大小；同一聊天和 iframe 保留，退出恢复分屏。

常用入口只有总览／编辑、创建和按需展开的关联；设置随选中对象出现，备份恢复放在更多菜单。

边界：最多 100 个节点／300 条边；不提供自动布局、协作、可执行逻辑或 Agent 多节点写入。聊天批注、改图提案和原生附件发送保留在根草图。子节点用途标签与边语义都提供给 Agent，冲突描述仍可能需要用户澄清。根草图选区重点不会因新增图读取而被绕过。
