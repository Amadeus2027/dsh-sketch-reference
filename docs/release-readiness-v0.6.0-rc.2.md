## 代码变化与一致性

- `src/host/record-bytes.ts`：WeakMap 缓存每个不可变记录的序列化大小。固定 DSH `KvTable` 契约保证记录不可变、entries 为快照、持久化成功后才发布内存变更。缓存不保存历史总量，重启重新计算；删除、替换和失败写入不需要回滚计数。仍为 O(记录数) 累计，没有改存储格式或写入队列。
- `repository.ts`、`edit-repository.ts`、`visual-repository.ts` 复用该计数。记录数量及字节配额不变。确认回执在 drawing CAS 前预检，避免配额错误导致部分应用；原有磁盘失败后的 mutationId 协调保留。
- `contracts.ts`、`advice.ts`、`service.ts`：成功分析批次记录原生附件引用。`core/image.ts` 提取现有 PNG 引用 Schema，`visual.ts` 保持原导出，避免循环依赖。只保存元数据，不保存 Base64、URL 或本地路径；旧 Batch 无此字段仍可读。未扩展跨会话读取权限。
- 无生产 UI、Header、SSE、Composer 或 Excalidraw 修改；未增加依赖、Agent 工具、模型调用或自动发送。
- 新增 `quota.test.ts`、配额微基准和隔离 PC 夹具；扩充 edits/service 测试。夹具不进入安装包，也不在生产自动激活。

## PC 原生 DSH 实机结果

本轮在 Windows 上运行官方固定 DSH Web 与安装后的 rc.2，使用真实原生会话、Composer、Agent 工具执行、Excalidraw 与附件存储。固定模型仅负责确定性输出；它不等同于真实 DeepSeek 理解能力。官方提供方禁用、无模型密钥。共 4 轮原生模拟 Agent 对话、12 个模型步骤及 9 次独立分析请求（含失败），真实 DeepSeek 网络请求为 0。

1. **安装、升级与恢复**：rc.1 → rc.2 官方安装保留 500 元素旧草稿，升级前后 revision、sceneDigest 相同。后续禁用、重启、重新启用，506 元素协作草图和 1950 元素压力草图仍在；批注、历史提议和 Composer 文字恢复。另建空 DSH_HOME，通过官方 CLI 新装最终候选包，实际打开空画板并返回原生聊天正常。
2. **原生输入**：预先输入文字并粘贴待发送 PNG，选中文本后从批注追问、纠正、修改，文字与附件均保留，插入不自动提交。附件之后由测试操作者明确发送，用于原生 Agent 回归；不是插件移除。没有把跨会话待发送附件恢复作为本轮已通过项目。
3. **focus**：实际选择一个元素并设置重点，结构读取只返回 1 个元素。focus 图片读取成功；请求全图时现有代码限制到 focus 图片，不泄露整图。清除重点后恢复普通读取。
4. **PNG 导出失败**：仅安装测试副本注入一次 canvas.toBlob 错误，显示错误后分析按钮重新可用，显式重试成功，批注和草图保留。最后恢复原始安装 HTML，复核正常打开。未修改生产 finally。
5. **分析异常**：模拟请求取消、10 秒超时（504）、格式错误均保留旧批次；没有自动重试。用户显式正常重试成功。宿主已有速率限制保留。
6. **编辑**：原生 Agent 生成移动、缩放及矩形/椭圆/菱形/独立文字/箭头的组合提议。预览前后保持 501 个可见元素、原 revision 和 digest；明确确认后为 506 个，五种新图形实际持久化。撤销回 501，重做回 506，五次快速撤销/重做结果正确。撤销后的版本元数据发生正常变化，不能声称全 sceneDigest 与原值相同。历史提示显示“曾应用 · 画板已变化”。非法参数、锁定/绑定/成组、过期 revision、CAS、取消及删除路径由既有单测覆盖；这些路径没有逐项补做本轮浏览器实机。
7. **布局 A/B**：1280×720 同会话、同文字草稿，禁用插件与启用但关闭画板时：页面高度均 720、Composer top=512/bottom=636、消息独立滚动区高 644/内容高 1305。开分栏后页面仍高 720，Composer bottom 仍 636（宽度变窄导致输入行高增加）。1920×1080 页面高 1080，分栏比例拖动实际变化，画板可关闭重开。原生工具卡片未隐藏。
8. **SSE 与 Header**：测试服务主动关闭连接，客户端从 1 → 0，显示断线与刷新入口；手动刷新后恢复 1，模拟模型步骤不增加。1950 元素画板五次完整启闭后关闭态连接为 0，保存、导出准备及分析计数不增加。第二组无状态观察的快速自动点击误触模型菜单，未计为完成次数；重新定位正常，不归因为插件错误。

## 附件生命周期与未解决边界

固定 `dsh-attachment-local` 实现对规范 PNG 做 SHA-256 内容寻址，重复发布校验已有对象；公开 `AttachmentStore` 没有安全释放/引用计数接口。成功批次有引用不代表自动清理：失败、取消、旧批次被替换及不同图片可能留下不可达对象。没有证据允许插件安全删除它们，故暂不开发自定义 GC。长期不同图片积累仍是宿主生命周期政策的限制。

Header 本轮未发现重复分析/订阅问题，不证明所有宿主生命周期排列都覆盖。SSE 仍需断线后手动刷新或重开，服务停机期间无法实时同步。首次计数和宿主写整个存储文件仍有成本。单进程既有队列维持配额一致性，不新增跨进程数据库承诺。

未执行：真实 DeepSeek 新请求、移动端、跨平台、数小时 soak、GC/堆快照泄漏分析、实时主题切换专项、新的大型应用/PPT验证。已有真实模型 MALFORMED_RESPONSE 与固定 Web 不消费 presentResult 的历史限制没有被本补丁解决，也未掩盖原生错误/卡片。

测试设施曾遇到 profile 中重复官方适配器注册、夹具包被识别成重复客户端源码，均通过隔离配置及独立夹具 package 修正；宿主尚未监听时打开浏览器曾出现连接拒绝，服务就绪后新页面正常。嵌套测试 profile 的 pnpm 安装添加了本地 importer，审阅后仅撤销这次生成的根锁文件变化，生产依赖未改变。这些不计为插件失败或通过项。
