## Windows 上的真实流程

使用已配置官方 DeepSeek 的原生 DSH Web profile、0.6.5 安装包与独立演示工作区。保留正常 DSH 工具和确认权限，不安装 mock-model／mock-native-agent 或测试 overlay，不为拍摄放宽权限。用 OBS 窗口捕获或系统录屏，开启真实鼠标显示；先完成登录与账号配置，录制窗口不包含凭据页和带 token 的登录地址。

1. **自然绘画，约 30 秒。** 用 Excalidraw 原生手绘风格形状画简洁的项目页草稿：导航、项目列表、右侧标签筛选。线条与文字清楚易读，保留一次有目的的撤销调整或单线划掉的旧想法即可，不故意画歪、堆涂改或制作复杂流程图。输入用途，等「已保存」。
2. **交给 Agent。** 添加 PNG，回原生聊天发送：「参考当前草图做一个项目页。先查看这个演示工作区，再创建 HTML/CSS/JS；项目列表可搜索，右侧是标签筛选，不改画板。请用正常 DSH 工具完成，最后说明怎样预览。」保留实际读取结构／PNG、目录检查、命令、文件写入和等待画面；不要预先运行脚本冒充 Agent 工具输出。
3. **真的打开成品。** 按 Agent 给出的运行方式预览页面；必要的 DSH 权限确认由人阅读后确认，失败或重试照实记录。不将 Codex 手写的页面当成 DS 成品。
4. **第二轮纠正。** 发送：「右侧不要统计卡片，只保留标签；筛选后给出空结果状态。」展示实际代码更新和页面变化，不仅展示聊天文字。
5. **回画板讨论。** 让 Agent 为右侧元素批注，点击定位并从菜单追问。若再请求移动图形，保留提议 → 预览 → 人确认 → 原生撤销；不要把代码更新与画板更新说成自动双向同步。

普通聊天不要求三条建议或先做独立 AI 分析。上述提示是例子，不是固定模型响应；模型不调用某个工具或失败时保留事实，不拼接别次回答。

## 导出与素材交接

保存原始录屏和实际源码／预览结果，在本地记录包 SHA256、DSH／模型路线、录制日期、输入方式和真实调用范围。原片和账户数据不直接提交 Git；检查公开画面无凭据、私人文件名或会话。README 可先放 30–60 秒短片，完整流程放独立视频链接；如果剪掉长等待，在来源说明中列出剪切点，不能把加速结果说成推理延迟。

录制工作机有 FFmpeg 时，可用跨平台 Node 工具将**完整原片**转换为 GIF：

```sh
node build/demo-gif.mjs original-recording.mp4 docs/assets/v0.6.5/agent-workflow.gif
```

工具仅缩放、重采样帧率和量化颜色，保持 1 倍速度，不剪辑、不合成 UI；附带原片摘要与时长记录。FFmpeg 是素材制作工具，**用户安装插件不需要它**。

替换主页前独立核对：实际草图／PNG版本、可见鼠标、真正发出的消息、实际工具与文件、网页可操作、第二轮反馈确实落实；说明人工介入和失败。只把通过这些核对的素材标为「真实 DeepSeek 完整工作流」。
