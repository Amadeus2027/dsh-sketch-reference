# v0.6.0-rc.1

这是正式Release前的候选版本，维护者尚未批准发布。固定DSH 0.2.1-alpha.1、Excalidraw 0.18.1，不新增依赖或模型服务。

## 实际变化

- Agent可提议任意方向的独立两点箭头，包括水平、竖直；以前仅右下方向。真实数学图中已完成“右侧说明指向左侧P”的预览、确认、撤销、重做。
- 箭头方向、跨度与绑定继续严格校验；固定原生转换器会使极小箭头塌缩或反向，因此每个非零跨度须大于1，提议入库前给出明确错误。旧记录可读，旧小箭头不能应用。
- 结构摘要报告当前有效视觉参考的实际尺寸，遵守focus，不读取或导出额外PNG。明确结构不含外观，不猜颜色、字体和描边。
- 极端转义文本下保持至少一个元素并裁短用途，标记purposeTruncated，继续遵守输出字节预算。
- 同步文字尺寸占位、样式手工调整、图片只缩不放等工具说明；Windows许可清单路径改为可复现的正斜线。

没有放松用户确认、版本/CAS、focus、会话隔离或原生撤销。

## 实际应用证据

真实DeepSeek在隔离可写工作区完成网页、三屏交互UI和5页可编辑PPTX；各有用户侧需求纠正。Codex独立浏览器/逐页渲染验收。数学初答出现模型理解错误，纠正与批注更新有效。普通PNG对照也完成简单UI，不能据此宣称插件生成质量或Token更优。
