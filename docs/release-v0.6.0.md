# DSH Sketch Reference v0.6.0

面向 Windows PC 的 DeepSeek Harness 原生可视化协作插件。正式包沿用冻结的 `0.6.0-rc.2` 运行代码，仅更新版本及发布文档，不新增功能或改变权限。发布状态以 GitHub Releases 为准。

## 核心能力

- Excalidraw 可编辑草图、自动保存、关闭恢复与会话隔离。
- Agent 按需读取已保存的结构与真实 PNG；用户设置的选区重点限制读取范围。
- 真实元素锚点批注，以及从批注进入 DSH 原生输入框追问、纠正或要求修改；保留原有文字和附件，不自动发送。
- Agent 生成受限修改提议，用户预览并明确确认后才能应用；保留 revision、CAS、恢复备份和 Excalidraw 原生撤销。
- 复用宿主聊天、工具卡片、主题与分栏，不提供第二套聊天界面，不因普通 UI 操作自动调用模型。

## v0.6.0 阶段变化

- 独立两点箭头支持不同方向，包括水平、竖直。继续拒绝固定原生转换器无法稳定处理的极小非零跨度（≤1）。旧记录保持可读。
- 结构摘要报告有效视觉参考的实际尺寸，遵守 focus；极端转义文本遵守输出预算并标记用途截断。不猜测结构数据未提供的颜色、字体或描边。
- 配额检查缓存不可变记录的字节数，避免反复序列化全部历史；容量与记录限制不变。修改确认和忽略检查增长后的提议容量，容量不足在修改画板前拒绝。
- 成功图片分析记录原生附件引用；旧批次兼容。纯结构分析拒绝无意义图片载荷，图片及混合分析保留真实 PNG 输入。
- Windows 许可清单路径规范化；补充容量边界、取消、超时、格式错误和显式重试回归。

## 安装与兼容

- 锁定验证宿主：DSH `0.2.1-alpha.1`，Excalidraw `0.18.1`。其他宿主版本、平台及移动端不作兼容承诺。
- 在 DSH 的 Web profile 中安装发布附件 `dsh-sketch-reference-0.6.0.tgz`：

```sh
dsh plugin --profile web add /绝对路径/dsh-sketch-reference-0.6.0.tgz
```

安装或升级前建议下载草图备份，退出并重启宿主。配置官方模型密钥应在 DSH 内完成，不发送到聊天或项目文件。

## 验证依据

冻结 rc.2 本地及 GitHub Actions 类型检查、19 个测试文件/174 项测试、构建、打包通过。Windows 安装后验证原生文字与待发 PNG 保留、focus、五类图形确认/撤销/重做、250/1950 元素保存、失败恢复，以及新装/升级/禁用/重启。正式化没有修改运行源码，沿用这些结果，不称为又一轮新的模型或实机验证。

此前真实 DeepSeek 在隔离工作区完成网页、三屏 UI 与五页可编辑 PPTX，并接收用户侧纠正；原生 PNG 对照也完成简单 UI，不能据此宣称插件的生成质量或 Token 消耗更优。

详见 [rc.2 验收和测量](release-readiness-v0.6.0-rc.2.md)、[真实应用验证](release-readiness-v0.6.0.md)、[原始反馈与截图](evidence/v0.6.0/README.md)。

## 已知限制

- 不同图片、失败或被替换的分析附件可能积累；记录引用不等于自动回收，固定宿主没有公开安全释放接口。
- 实时同步断线后需手动刷新批注或重开画板；绘图和保存仍可使用。
- 真实模型可能误读草图或输出无效工具参数；历史 `MALFORMED_RESPONSE` 没有被此版本消除。失败提示、用户纠正和修改确认仍然必要。
- 修改工具只支持现有白名单操作，不能任意编辑样式、锁定、绑定或成组图形。固定 Web 不直接消费 presentResult，保留正常原生工具卡片。
- 数小时持续运行、堆快照泄漏分析及所有历史升级组合未覆盖；不宣称长期无泄漏或全平台兼容。

后续版本优先处理实际反馈与发布缺陷，不扩张本次冻结范围。
