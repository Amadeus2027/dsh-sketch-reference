## 自由笔迹缺陷与候选修复

原版复现：画两笔→等待保存/设置重点以 settle→关闭→重开，不再编辑。revision `26e1f08a-9af8-419f-a48c-9eb4e03ca739`→`c7c2b733-9893-4bcb-84f0-5ce58bd5d680`。逐字段只有两笔 lastCommittedPoint 从坐标变 null，却改变 sceneDigest/contentDigest。准备好的图片会过期，旧批注/提议存在被误判过期风险。

修复在 `src/editor/scene.ts` 及三个编辑器调用点：新笔迹存 null；已有笔迹按 ID 保留上一场景的 checkpoint（含历史缺省），避免迁移写入破坏旧 revision。真实坐标/点集等仍参与保存和摘要。未改变宿主 CAS、协议、存储格式或模型提示。

候选基于 main 加本地修改，package version 仍为 0.3.2，**不是官方新 Release**。tgz SHA256 `0CF2F1CFF52D47D9B6A8A027594C79F60AF4F7AC8A7E55C609159554BB947C82`，安装到 sketch-local-check，415 个代码文件零不一致。原版包/证据保留，隔离故障 profile 仍为原版。

复验：

- 先补回归、原实现失败；修复后 128 项单测/15 文件、typecheck、bundle、pack、git diff --check 通过。新增覆盖新笔迹及历史 null/坐标/缺省 checkpoint，真实移动仍保存并改变摘要。
- 原版新增第三笔带 `[180,0]`，安装候选并重启宿主后重开，revision `67682b62-35c1-4d74-bb5e-56230e9bff5b`、两个摘要不变，历史字段保留。

## 故障、性能与证据边界

保存 503、双窗口来源更新、SSE 断开使用仅代理指定插件 RPC/SSE 的本地夹具，仅作用于隔离 win032-clean profile；无模型代理，未改官方地址、密钥或日常浏览器设置。250 元素覆盖该隔离会话的可丢弃场景。

250 元素：50 次原生按键移动自动化耗时 1436ms，1 保存；50 次平移耗时 5722ms，0 保存/0 模型。它们不是 50 帧基准。20 次开关约 3086–3114ms/次，含自动化等待，关闭连接均归零，保存计数恒为 5。宿主 RSS 187183104→185638912 bytes，未强制 GC；浏览器 heap/长任务/字体缓存未完整测量，不能宣称无泄漏或性能提升。

证据在忽略目录 test-results：win032-reinstall-evidence.json、win032-recovery-evidence.json、win032-native-image-blocks.json、win032-states-before-restart.json/after、win032-preview-invariant.json、win032-lifecycle-20.json、win032-performance-partial.json、win032-hydration-before.json/after、win032-legacy-candidate-before.json/after、win032-candidate-new-evidence.json、win032-candidate-true-edit.json、win032-candidate-installed.json 及截图。原生 zstd 按拼接帧逐帧读取、只提取 image block；首帧只有头部，单次解压不能据此否定图片历史。
