## 模块职责与实际改动

| 模块 | 维护边界 |
| --- | --- |
| `src/host/transport.ts` | 统一静态资源、RPC、SSE 的认证与注册／撤销。旧版沿用 requestRejection；新版要求 required-auth 路由传入有效 Peer，不读取未注入的认证子服务。部分注册失败时撤销已注册路由。 |
| `src/client/conversation-layout.ts` | 单独管理原生聊天的 hero／settling／active 状态；新版不再等待旧 parentAvailable，工作区选择交还原生回调。 |
| `src/client/harness-draft-bridge.ts` | 新版普通会话使用原生图片上传参数，子代理保留内联图片路径；旧版忽略第三参数，原有回滚与既有附件保护保留。 |
| `src/editor/graph-thumbnails.ts` | 每个工作区最多同时导出两张 PNG；文档读取保留原来的请求流程，排队的旧版本被淘汰时不启动；保留版本缓存、失败重试、关闭取消与 URL 回收。 |

静态资源工厂由“每次请求构造”改为“每次注册构造”，减少重复的资产根目录 realpath；逐文件路径检查、CSP 与认证不变。原绘图队列、CAS、mutationId、owner、存储键及数据格式不变。没有重写 Excalidraw、升级 React／React Flow 或添加通用状态框架。

开发类型固定到 DSH alpha.2／Cordis 4.2；增加两个官方声明依赖，避免缺失声明被 skipLibCheck 掩盖成 any。Zod 从原锁定 4.6.5 对齐到 4.6.6 并固定，解决多副本声明不兼容；许可清单随包更新。其他编辑器与构建工具的声明版本保持原样。peer 只增加已选目标版本及相应 Cordis／Schemastery 范围，没有开放所有后续版本。

## 有限性能观测

## 检查结果

`pnpm run typecheck`、26 文件／236 项单测、`pnpm run bundle`、`pnpm pack` 与 `git diff --check` 通过。基础绘图未观察到稳定提速，首次打开与重开样本略慢；本轮收益主要是限制 PNG 峰值并发、复用静态资源处理器，以及修复新版宿主不能使用的接口。没有用单次小幅差异计算提速百分比。

## 测试发现与未验收范围

- 首次最新宿主验证暴露 Cordis 4.2 的子服务注入保护；修正后通过原生回归，单测保留会抛错的受保护属性复现。
- 首轮同时限制了文档读取与导出，真实大图回归发现热缓存检查仍有 69 次排队读取；最终只限制 PNG 导出，保留原文档读取流程，并重跑对应回归。
- 重复安装同版本同名 tgz 曾命中旧代码缓存；改用唯一文件路径后逐文件核对实装。不能把旧包结果视为最终包结果。
- 新版首次登录弹窗、异步工作区菜单及空模型选择需要调整测试准备；脚本模型测试显式验证隔离标志后才选择测试模型。原生 Agent 用真实宿主循环与工具，但回答为脚本，不代表模型理解或 Token 节省。
- Windows／Desktop、真实 DeepSeek、PTC／其他预设、全部插件组合、跨宿主历史数据迁移与长期资源行为未完整验证。旧版本的真实模型记录不改称本轮结果；满载图仍可能掉帧，未新增整图撤销或复杂绑定支持。

## Windows 精简复验

1. 备份并退出宿主，安装包含本次改动的 CI 包；保留原 profile 和存储。
2. 在原会话与新会话检查绘图、保存、主题、开关／全屏及 PNG／可编辑备份。
3. 原生输入已有文字和附件时加入参考图、确认不重复；配置自己的视觉模型后检查读取、批注、追问与提议确认／撤销。
4. 总览拖动／缩放并返回编辑，关闭重开核对最终位置；中断保存时保留副本，重试后检查 CAS 不覆盖新版本。
