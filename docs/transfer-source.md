# 获取源码

当前支持源码 ZIP → 构建 → DSH 官方管理器添加目录，无需先生成 TGZ，详见 [源码安装](installation.md#从源码-zip-目录直接安装)。GitHub Release 同时提供预构建包。

开发者也可克隆：

```sh
git clone https://github.com/Amadeus2027/dsh-sketch-reference.git
cd dsh-sketch-reference
```

早期离线 `.bundle` 交接说明已退役；它不是当前 Release 附件，不再提示用户下载不存在的文件。[历史交接原文](https://github.com/Amadeus2027/dsh-sketch-reference/blob/114f3bf4ede6230c9bcabbd4a1eec13a72129b22/docs/transfer-source.md) · [开发与 PR 流程](../CONTRIBUTING.md)
