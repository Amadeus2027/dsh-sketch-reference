# Sketch Graph 性能与交互修复（2026-10-17）

基线 `main@9221644`，版本仍为 `0.7.0-alpha.1`。对照维护者提供的 DeepSeek 第三轮建议，按 Karpathy Guidelines 先复现、再小范围修复；不新增依赖、模型调用或存储迁移。

## 本轮处理

- **高频布局保存**：节点移动／视口变化只更新内存，连续操作每 500ms 校验并写一次本地恢复检查点；手势结束再次检查，之后沿用 300ms 自动保存。拖动持续时取消旧的自动保存定时器。关闭、打开草图、页面隐藏／离开和组件清理均处理尚未写出的布局。结构性修改仍立即持久保存请求；CAS、mutationId、单请求串行、失败重试和未确认副本保持原逻辑。同一恢复记录不再在发送时重复序列化写入。
- **缩略图缓存**：缓存属于单个工作区，最多 100 项，包含空白草图、正在进行的请求和导出图片。用新只读 RPC `graph/document-revisions` 获取最多 100 个节点的 ID／revision，不传场景或用途；返回总览时用一次此请求核对全部版本，仅重取发生变化的文档。另一窗口修改也会失效，不能仅凭“当前编辑节点”决定刷新。删除节点／版本变化／关闭工作区释放 URL，取消请求；导出中迟到的 URL 也释放。版本请求失败时禁用缓存复用并按需读文档，基础编辑仍可用。
- **位置查找**：用 React Flow 提供的 position changes 按 ID 建索引，不再为每个节点线性搜索全体节点；未移动节点保留引用。移除用于刷新全部预览的 React Flow key，载入服务器版本时通过公开 `setViewport` 同步视口。
- **小交互**：图保存的 dirty 文案改为“待保存…”。细节关联不提供 root，已选 root 后切为细节时重置目标。小于 8px 的无效框选继续等待下一次拖动。
- **版本说明**：中英文 README 明示 main／源码 ZIP／对应 CI 包为 0.7.0 开发预览，正式 latest Release 仍为 0.6.5；保留两种安装方式。

500ms 检查点只用于布局。正常松手、导航和页面生命周期会立即补记末次布局；硬断电／强杀进程仍可能丢失尚未到检查点的最后一小段位置变化。单张草图的绘制保存队列未改。没有把“延迟写入”描述成每帧都已落盘。

## 未照搬的建议

- **级联扫描**：最新基线已只在删除节点或补偿失败清理时扫描；移动、改名、连线和相同内容重试均跳过。现有单测已覆盖，没有重复改造。
- **整图撤销**：暂缓。删除节点会清理草稿、批注和视觉记录，仅保存 20 个 GraphContent 快照不能恢复这些数据，不应做成看似成功的撤销。仍保留删除确认和备份／追加恢复。
- **搜索／重名规则**：属于新增交互与数据策略，本轮不扩展。没有对已有同名节点或备份新增不兼容校验。
- 保留新增节点只读的 Agent 边界，不扩展图级 Agent 写入。

## 复现

```sh
pnpm run typecheck
pnpm test
pnpm run bundle
pnpm run verify:distribution
pnpm pack
CHROMIUM_PATH=/usr/bin/chromium pnpm run test:browser:graph
```

实装前先在专用 profile 安装同次构建 tgz，测试覆盖层复制到安装 profile 内。设置该宿主的 `DSH_SMOKE_URL`、`DSH_TEST_WORKSPACE`、`DSH_TEST_OUTPUT` 与 `CHROMIUM_PATH`：

```sh
pnpm run test:browser:graph-stability
pnpm run test:browser:native
pnpm run test:browser
# 真正退出并重启同一宿主；更新 URL，保留相同输出目录
DSH_GRAPH_VERIFY=restart pnpm run test:browser:graph-stability
```

同脚本对照使用 `9221644` 的原版 `tests/browser-graph.mjs`：在基线和修复版构建后分别执行，将结果另存，勿以扩展回归的结果混充该对照。

## 测试中发现的问题

第一版合并布局虽然减少了每帧校验，但未取消先前的自动保存计时器，连续两秒拖动仍写入 15 次恢复记录，新增浏览器断言失败。继续拖动时取消旧计时器后，该断言记录 4 次，并补充“连续手势期间不发请求”的单测。原有 RPC／CAS／故障和实装套件在最终代码重跑通过，早期失败不记作通过。
