# v0.6.4 Windows 双版本验收

这是一份待执行清单，不是 Windows 通过报告。云端脚本模型结果见 [验证记录](validation-v0.6.4.md)。继续使用 Windows 上已配置的 DSH 官方模型，不上传凭据、登录地址或原始私人会话。

## 包与环境身份

- 同一个 v0.6.4 tgz，记录 SHA256；分别确认 `dsh --version` 为 `0.2.1-alpha.1`／`0.2.1-alpha.2`。
- 固定 Excalidraw 0.18.1、React 18.3.1；记录 Node、浏览器版本与 DPI。
- 在独立测试 Web profile 中试装，保留日常 profile。不要把 Web CLI 版本与桌面 GUI 安装版混称。
- 两个宿主不同时写入同一测试存储；切换版本先退出旧宿主。

## 两版都执行

- [ ] 默认安装成功，无 `allow-version`；参考板入口只出现一次。
- [ ] 原输入文字与已有 PNG 保留；打开、关闭、重开画板后仍能继续编辑。
- [ ] 画三个简单区域、中文标签、少量自由笔迹；保存、PNG 和 `.excalidraw` 导出可用。
- [ ] 浅色／深色／系统主题与自定义文字字体同步；保持画板打开切换，不重载、不改变 revision。
- [ ] 调整分栏、窗口与 DPI；输入框、菜单、画板与批注不遮挡，原生聊天正常滚动。
- [ ] 原生聊天读取整图／局部；自由笔迹确实使用当前 PNG，不把结构摘要当成识别结果。
- [ ] 有效元素批注点击定位；全局／缺失锚点不误绑；移动、缩放、平移正确跟随。
- [ ] 超过三条批注翻页；解决、重新打开、忽略、追问／纠正；不自动发送或调用模型。
- [ ] Agent 提议后检查前后预览；明确确认才改图；原生撤销与修改前备份可恢复。
- [ ] 提议后继续手改／修改用途；旧提议无法覆盖最新 revision。
- [ ] 分别检查独立图片、结构、混合分析；仅结构不注册 PNG；取消保留旧结果与草稿。
- [ ] 模型不可用、断网／超时，仍能绘图、保存、导出；明确记录真实故障与模拟注入区别。
- [ ] 会话切换、删除／恢复与宿主重启；无批注串用，参考板不会重复初始化。
- [ ] 关闭宿主后移除插件；宿主能启动，入口消失。不要把这种验证写成热卸载通过。

## 旧数据与 alpha.2 专项

- [ ] alpha.1 + v0.6.3 留一份已保存草图，两类批注、解决状态、待应用提议、视口与未发送文字。升级 v0.6.4 后重开原会话，逐项对比，不导入替代数据。
- [ ] 在 alpha.2 测试同一会话：通过原生 `working_directory` 进入已有测试目录／工作树；画板保持、owner 不变、草图与批注不丢失。
- [ ] 目录变化后再次保存，旧 revision 不能覆盖；切换另一会话继续隔离。
- [ ] 重启 alpha.2 后复核草稿与两类批注／提议／PNG 缓存。选区重点按原设计重新设置。

## 5 分钟演示

1. **30 秒**：说明非官方插件、Web profile 和宿主版本，展示包身份。
2. **60 秒**：在当前会话画导航、内容、侧栏三个简单区域，加入参考图，保留原生输入。
3. **90 秒**：原生聊天询问布局；Agent 读当前草图并添加两条锚定解释，点击批注纠正一处。
4. **90 秒**：要求移动一个独立矩形，检查修改预览，确认后原生撤销。
5. **30 秒**：关板重开展示保存；说明真实模型可能误读、无外部密钥、版本与待验收边界。

展示实际运行结果，失败就保留并说明，不用固定脚本结果替代真实 DS 回答。数学正确性、生产级网页/PPT 质量和 Token 节省不作泛化承诺。
