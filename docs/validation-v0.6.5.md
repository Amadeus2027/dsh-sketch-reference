# v0.6.5 验证记录

日期：2026-10-12 UTC。基线 main `0de23f2`（已合并 v0.6.4 PR #25）；DSH Web alpha.1 / alpha.2、Excalidraw 0.18.1、React 18.3.1。Linux、Node 24.19.0、Chromium 151。无依赖升级、存储迁移或协议变化。

## 实际改动

1. notice 普通状态旧规则仍为橙色背景和普通文字；只有 info 是 DeepSeek 蓝。现在基础 notice 与按钮共用原生蓝色变量，删除 info 重复覆盖；空建议摘要同样蓝色。告警文字／role 与重试保留。
2. 原生 line/arrow 在 pointer down 后可暂时只有一个点，SceneUpdates 的 80ms 合并会使正常手绘留下严格校验错误。仅根据公开 newElement / multiElement 草稿状态延后此临时快照，保留最后完整版本；完成后照常处理，持久化 Schema 没放宽，非草稿错误不屏蔽。
3. 新 prepack 检查宿主、客户端、编辑器 JS/CSS、九字体族、宿主 Zod 声明与许可；在解开实际 tgz 的目录复验通过，缺失 Xiaolai 字体负例被拒绝。CI 增加与包配对的 SHA256SUMS.txt，产物下载即可安装，不需要开发构建。
4. 主页演示改为原生手绘风格布局的连续屏幕录制，保留系统鼠标、撤销重画、等待保存、PNG、输入未发送需求与重开。输入仍由自动化驱动，不是假称真人或真实模型执行。
