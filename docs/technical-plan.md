# 技术方案与 10 月 13 日验收计划

基线：DSH 0.2.1-alpha.1，Excalidraw 0.18.1。开发日期 2026-10-08。项目从空仓库建立。

## 首版结构

宿主 Cordis 服务提供静态编辑器和同源 JSON RPC；独立 iframe 运行 Excalidraw/React；宿主客户端采用公开插槽与会话内容工厂分栏。iframe 和父页面以来源、窗口、会话与随机 nonce 验证后建立 MessageChannel。

`drawing/get` 解析会话生命身份并返回草稿、建议和可用官方模型；`drawing/save` 使用预期 revision 和 mutationId 保存；`model/check` 校验模型图片能力；`advice/generate` 固定保存版本，注册图片附件并调用 `llm.stream`，只接受正常终止后的受限 JSON。取消通过 fetch 断开、宿主响应关闭与 AbortSignal 传播；没有独立取消 RPC，也没有默认重试。

使用建议前父页面再次比较服务端最新草图与建议内容摘要。参考图通过控制器注册浏览器 File，交给原有附件输入；不自动提交任务。失败保留图与用途。编辑 metadata 不影响建议内容摘要。

场景不含图片/iframe/外链，JSON 大小、元素数、深度受限；静态路径拒绝目录穿越，CSP 限制编辑器本地资源。接口要求 loopback Host、同源 Origin，复用宿主路由保护，不单独建立账户系统。

## 原方案首版调整

- 同时支持 `deepseek-account` 与 `deepseek-official`，不会悄悄回退认证路线。
- 每会话保留最新建议，不实现多快照历史、建议请求缓存/跨窗口共享。
- 固定版本头部映射解决插槽单一声明者限制；0.2.1 已通过公开登记订阅动态同步扩展。
- 首版不实现自动裁剪极端长宽草图、文字可读性诊断或附件生命周期清理；PNG 完整范围导出并限制尺寸/字节。非常宽的草图应拆分后分析。
- 生成与附件桥尚需有效 DS 配置的真实验收。代码和模拟模型契约测试不能证明模型效果。

## 人工验收

- 普通/新建/切换会话、宽屏/窄屏、关闭重开保持可编辑图与用途。
- 两窗口写同一会话触发冲突，失败本地副本可导出；会话删除/重建不串图。
- 中文图导出实际可读；无 CDN；检查完整范围与长宽边界。
- 主输入已有文字及附件时，插入建议与加入 PNG 保留已有内容；不自动发送，不悄悄换模型。
- 图片变化后旧建议禁用；错误模型、断网、取消、超时不会展示伪结果。
- 真实模型至少覆盖有效图、空图、中文用途、取消、限流，以及建议对最终网页布局的实际影响。


## 2026-10-08：0.2.0 增量方案

在首版会话、绘图 CAS、恢复和原生附件桥之上增加混合输入与元素锚点批注，保持固定 DSH/Excalidraw 版本。默认仅在用户点击分析时发送 PNG、用途和受限元素数据；模型关联真实元素 ID，插件以 Excalidraw 公开 API 确定坐标和跟随，不生成正式批注图形。

批注使用独立 CAS 状态，旧建议读取时兼容，修改草图后继续过期；模型与定位失败保留全局建议或原生参考工作流。三种输入模式提供真实对比脚本，当前没有有效 DS 凭据，效果与定位准确率仍待真实调用。详细协议、存储升级/回退边界和验收见 [AI 锚点批注与混合输入](anchored-comments.md)，执行证据见 [验证记录](validation.md)。

## 2026-10-08：0.2.1 原生集成与性能

继续使用 Cordis 服务、会话插槽、原生输入工厂、iframe/MessageChannel 与现有模型/附件路线。新增可选公开主题同步、按插件生命周期拥有的面板与样式、事件握手和关闭保存流程；合并绘图快照并缓存当前 PNG，扩大绘图区，折叠建议、导出和模型设置。没有新模型服务、依赖升级或存储格式变更。

接口审计、开源参考、可复现性能数据、末次保存限制与验收见 [原生化与性能说明](native-integration.md)。真实 DeepSeek 和真实 Agent 任务仍按原排期验收。

## 2026-10-08：0.3.x 原生通用协作分阶段目标

0.3.0 实施 P0：原生聊天按需读取已保存草图、渐进获取元素、通用说明与可选元素批注；保留原分析、绘图、导出、附件、恢复及独立版本比较。用途扩展为物品、数学、流程、机械和 UI 等自由草图。普通问答使用 DSH Agent，插件不额外调用建议模型，不自动注入完整图片/场景。

0.3.1 的 P1 为受限修改提议、预览、用户确认、版本拒绝与原生撤销；0.3.2 的 P2 为选区聚焦与持续迭代。这两阶段尚未开发，也不是 0.3.0 的完成条件。真实识别、定位与回答质量需有效 DeepSeek 配置验证；部署与代码测试不能替代模型效果证据。详细协议、阶段范围、实测数据与手动验收见 [Agent 协作说明](agent-collaboration.md)。
