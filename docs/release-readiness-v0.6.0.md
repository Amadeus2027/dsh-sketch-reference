### 测试设施限制（非生产插件修改）

- AppContainer 匿名子进程管道不兼容：用文件描述符捕获 spawn/spawnSync/execFile/exec，真实子进程仍在容器内。直接 PowerShell 调 Node 输出/退出码不可靠，DS 自主用 Start-Process 与重定向恢复。
- 原生文件原子覆盖需要 WRITE_DAC，仅应用目录授予完全控制；源码和私人文件边界不变。早期 grantWrite/SetFileSecurityW 失败不计插件缺陷。
- 本地 PowerShell 执行器缺少原生 sandboxMode，权限预设服务警告；应用测试不能证明原生沙箱全部兼容。
- 高 CPU/请求停滞在移除插件后也复现；补齐 execFile 适配后同一 home 恢复，不声称所有冻结根因已解决。
- 多个同源 DSH 标签及 SSE 长连接占用造成 RPC 超时；并行研究使用同后端、不同 loopback 端口后恢复。未因此重建生产通信系统。
- 转发诊断曾错误解析 multipart 请求；已修复设施诊断，不让诊断异常覆盖有效官方响应。
