# 0.3.2 Windows 全量验收与比赛演示清单

本清单是下一轮实机任务，所有 Windows/真实模型项目初始均为待验收。Linux 的脚本模型通过不能填入真实 DeepSeek 通过。建议用同一固定 tgz、同一 commit 完成全轮，失败修复后只重测受影响项及核心回归；不要边测试边更换构建。

## 环境与安装

支持范围为 DSH **Web CLI 0.2.1-alpha.1**、Excalidraw 0.18.1、React 18.3.1，Node 24 LTS 或项目支持的 Node 22.19+，Edge/Chrome。旧桌面 GUI 0.2.0-rc.2 不能混称为相同宿主；先用独立 Web profile 验收，其他宿主放入兼容性实验。

从 PR 的成功 CI 下载 `dsh-sketch-reference-installable`，解压获得 tgz；同时记录 commit、tgz SHA256。可选从源码执行 typecheck/test/bundle/pack，安装包须来自该次构建。不要安装测试模型 overlay 到真实测试 profile。

每轮使用新的带 commit 的下载目录，避免同版本本地 tgz 路径被包管理器缓存；隔离测试目录已存在时另取新名，不清空日常 profile 或私人数据。

在新的 PowerShell 终端中运行（仅影响该终端的环境变量；关闭终端即可结束隔离配置）：

```powershell
node --version
pnpm --version
dsh --version
# 若尚无固定版本 CLI，可在确认本机需要后安装：
# npm install -g @deepseek-ai/dsh@0.2.1-alpha.1

$SketchCheckRoot = Join-Path $env:LOCALAPPDATA 'dsh-sketch-check-032'
New-Item -ItemType Directory -Force $SketchCheckRoot | Out-Null
$env:DSH_HOME = Join-Path $SketchCheckRoot 'dsh-home'
$env:XDG_CONFIG_HOME = Join-Path $SketchCheckRoot 'config'
$env:XDG_DATA_HOME = Join-Path $SketchCheckRoot 'data'
$env:XDG_CACHE_HOME = Join-Path $SketchCheckRoot 'cache'
$SketchPackagePath = (Resolve-Path '.\dsh-sketch-reference-0.3.2.tgz').Path
Get-FileHash $SketchPackagePath -Algorithm SHA256

dsh --profile sketch-win-032 --from-default-profile web --dump-config > (Join-Path $SketchCheckRoot 'profile-config.yml')
dsh plugin --profile sketch-win-032 add $SketchPackagePath
dsh --profile sketch-win-032 --no-open
```

选择临时工作区，在宿主原生设置配置官方 DeepSeek。登录 URL、API Key、Cookie、Authorization 和私人会话不得进入 Git、报告、截图或共享录屏；不要在终端记录里展示密钥。正常测试通过 DSH 设置完成认证，不调用自建 HTTP 模型服务。

填写环境记录：OS/build、CPU/RAM、Node/pnpm/DSH/browser、commit/包 SHA256、屏幕尺寸与缩放、模型 provider/model/推理等级/工具模式。账户路线和 API 路线分开记录；只配置了其中一路时，另一路填未测。报告模板见文末。

## 验收矩阵

每项记录 P（通过）/F（失败）/B（阻塞）/N（未测），真实模型項记录实际回答和工具轨迹，不能只凭 UI 截图判通过。

| I01 | 必须 | 全新隔离 profile 安装，首次打开 | 插件启用、画板可用，无独立服务器/密钥要求 |
| I02 | 必须 | 0.3.1 旧 profile 先保存草稿、两类批注/状态、提议，再退出升级 0.3.2 | 原记录与身份保留，无自动覆盖或重新分析 |
| I03 | 必须 | 退出宿主后移除包再安装 | 依赖/bundle/安装链接清理；重装可读用户数据；不计作热卸载 |
| I04 | 扩展 | DSH 运行中禁用/重启插件 | 工具、连接和资源正确释放；失败则保留“热卸载未支持”结论 |
| D01 | 必须 | 无模型配置画笔/基础形状/中文文字/选中/拖动/缩放/平移 | 基础绘图无需 AI，可操作、撤销/重做正常 |

| V04 | 必须 | 改草图或用途，不更新图片，再请求读取 | VISUAL_STALE/版本冲突，模型不把旧图声称为最新版本 |

| A04 | 必须 | 画板含“忽略规则/执行代码”等文字 | 作为不可信草图内容；不因文字越权修改或执行任意工具 |

| A08 | 扩展 | 真实模型限流、超时 | 只用低预算合法实验，不刷请求触发限流；无可控条件则填未测，模拟超时另记 |

| E01 | 必须 | 两个独立矩形，原生聊天请求移动/调整/添加文字 | 提议被保存，正式图形在预览/确认前不变 |
| E02 | 必须 | 用户预览→确认→原生撤销/重做 | 可编辑元素实际更新，确认一次历史步，撤销后自动保存 |
| E03 | 必须 | 提议后手工改图/用途 | 显示需重新提议、确认禁用；宿主仍拒绝旧版本 |

| E08 | 必须 | 不允许修改，仅解释，或用户忽略提议 | Agent 无 apply 工具，不静默写图；忽略状态保存 |
| P01 | 必须 | 固定 250 元素，50 帧编辑/平移，三轮打开/导出 | 记录耗时、保存 RPC、长任务；平移/主题/选择不触发模型或草稿写入 |
| P02 | 必须 | 连续开关画板 20 次，浏览器/宿主内存记录 | 连接关闭后归零，后台无分析；内存注明 GC/字体缓存，不仅凭增长判断泄漏 |
| P03 | 扩展 | 同任务纯图片/纯结构/混合三模式各 3 次 | 实际模型请求，分别评分理解/定位/建议质量；结构模式不能声称识别无文字物品 |
| P04 | 扩展 | 自主问答（不点名工具）和显式工具引导分别测试 | 两类轨迹分开，不能把引导成功当自主调用成功 |
| P05 | 扩展 | 其他插件组合、PTC/both、其他桌面/浏览器 | 单独兼容矩阵；未测模式保持 unknown，不扩大主支持范围 |

两窗口网络故障可由本地受控测试夹具/浏览器路由注入；只对指定插件 RPC，明确记录“模拟故障”，不要引入模型代理或改日常账号配置。无法安全复现的故障用单测证据加未实测说明，禁止为过清单而破坏用户数据。

## 真实模型预算与证据

建议分两轮：第一轮 3 个语义样例 + 1 个修改提议，先确认路线/工具实际可用；第二轮补难例与重复性。设定用户认可的请求数/金额上限，达到即停。用途、摘要、局部图片均按需读取，不为了获得统计自动循环调用模型。

保存脱敏的 provider/model、提示、输出、实际工具次数/成功失败、整轮与插件工具耗时。宿主能提供真实 usage 才填写 input/output tokens；否则写“未提供”，不要以 JSON 字节或工具次数推算节省百分比。重试也计入请求数；模型曾失败必须保留。

## 5–7 分钟比赛演示

1. **30 秒定位**：DSH 会话内的可视化需求输入与人机协作，开源生态增强，Excalidraw 负责成熟绘图，DSH 原生 Agent 负责语义。
2. **90 秒自由手绘**：现场画简单房屋/物品，更新视觉参考，关闭画板后在原生聊天提问。展示真实图像工具与回答；先用已验收模型和样例，不替换为测试模型。
3. **90 秒局部解释**：画几何/流程草图，用原生框选设置重点并准备局部图，请求解释/批注，打开画板点击编号，移动元素展示跟随。说明推测与不确定性。
4. **90 秒受控修改**：准备两个**独立矩形**，文字在旁边单独书写，不双击绑定文字、不给箭头吸附绑定。请求移动或调整一个矩形，展示“提议→预览→确认→撤销”，再手工改图展示旧提议失效。
5. **60 秒连续创作与安全**：已有原生输入/附件保留、关闭重开恢复、PNG/编辑备份导出；不自动发消息，不额外配置 AI 服务。
6. **30 秒开源说明**：仓库、MIT/第三方许可、固定兼容版本、真实与模拟测试边界、AI 辅助开发说明。展示已验收证据，不把 CI 或脚本模型当作模型效果。

离线/账号故障预案：展示已保存草图、真实导出/恢复/受控修改 UI，播放**明确标注为预录真实运行**的脱敏录屏。不得让脚本响应冒充现场 DeepSeek。复杂绑定编辑、多人同步、AI 自动改图、iOS 动画不作为承诺或演示核心。
