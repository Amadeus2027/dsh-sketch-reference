## 实现改动与复用

1. line/arrow 结构包含最多 32 个有符号局部 `points`，附截断标志。angle=0 时额外给出精确平移的 `scenePoints`，供 DS 核对方向与闭合；旋转元素明确标记不能直接换算，不采用 DS 提出的错误绕 x/y 旋转公式。自由笔迹及自定义元数据不会整段发送。
2. 活跃重点强制限制 Agent 的结构与图片读取，包括显式 `scope=all`。旧重点拒绝读取；缺失重点图片不代用整图；批注锚点不能越界。清除重点后恢复整图。此功能不是聊天历史或其他宿主工具的安全隔离：旧附件、历史信息、用途和整图元素总数仍可能存在，修改提议也不是全局重点权限沙箱。
3. 原生分析菜单提供“图片与结构 / 仅图片 / 仅结构”。纯结构跳过 PNG 导出、校验和附件发送，官方文本模型可走此路径；真实无视觉路线本轮仍未配置，只完成自动化覆盖。
4. 窗口根据实际聊天列宽切换布局；画板打开时临时将匹配的 DSH 宿主 grid 设为 `overflow:clip`，阻止隐藏侧栏内容导致整个 grid 横向滚动；关闭时释放并恢复原样式。适配锁定的宿主布局，其他 DSH 版本需重验。
5. 工具说明及读取结果都携带“画法不是数学条件、用途不是已经画出的事实、最小充分回答”的解释边界。实测证明提示规则仍不能保证 DS 数学正确。

继续复用已锁定的 Excalidraw 0.18.1 原生画布、选择、导出、恢复和编辑能力，保留 MIT 许可及现有第三方声明；本轮没有另造绘图器或复制未授权素材。新增端点表达直接遵循元素实际数据。公开 API 参考：[工具函数](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/utils)、[Excalidraw API](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/props/excalidraw-api)。

## 性能记录的解释

被动计数脚本只封装 Canvas 导出与 Storage.setItem 并收集 RAF、longtask、堆采样，没有修改场景或访问编辑器私有 API。夹具经公开草稿 RPC 保存到独立的新会话，不调用模型。测试代理仅监听本机57324，结束后已停止；主57317保持运行且插件已启用。
