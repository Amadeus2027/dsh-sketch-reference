# 0.6.0-rc.2

正式发布前的 PC 稳定性候选更新，继续兼容 DSH `0.2.1-alpha.1` 和 Excalidraw `0.18.1`，不升级固定依赖。

- 历史草稿较多时，配额检查复用不可变记录的字节数，避免每次保存重复序列化全部历史；容量、记录限制及 CAS 不变。
- 修改确认与忽略也检查增长后的提议容量；容量不足会在修改画板之前拒绝。
- 成功的图片分析记录原生附件引用，便于追溯。旧分析兼容；没有自动附件清理功能。
- 纯结构分析拒绝无意义的图片载荷；图片和混合分析继续保留真实 PNG 输入。
- 补充取消、超时、错误格式、容量边界及重试回归，164 → 174 项测试。
- Windows 已验证批注操作保留原生输入文字与 PNG、五类新建图形确认/撤销/重做、250/1950 元素保存，以及插件升级、禁用与重启。没有新增后台模型调用。

本轮使用固定模拟 Agent 验证工程流程，没有重新评测 DeepSeek 理解能力。SSE 断线仍由用户刷新恢复；不同图片的宿主附件增长仍需宿主回收政策。完整测量、证据和未覆盖范围见 [验收报告](release-readiness-v0.6.0-rc.2.md)。

此版本是候选包，尚未正式发布。合并、打 tag 和发布由维护者决定。
