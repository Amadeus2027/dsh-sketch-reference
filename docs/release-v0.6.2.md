# DSH Sketch Reference 0.6.2

本次集中改善批注的信息密度和操作位置，保持 DSH 原生聊天及 Excalidraw 0.18.1。

- 移除重复的顶部摘要和卡片正文。顶部保留标题和必要状态，详情在画板内显示；没有具体批注时仍显示分析结果。
- 追问、纠正、修改及状态操作只出现在画板内批注卡片的「⋯」更多菜单。上方只保留标题；刷新批注移到展开入口同一行的右侧。
- 批注标记改为清晰的圆角数字标签，使用直立系统字体；展开入口使用按钮底色、计数和 SVG 箭头。
- 标题卡选中时使用浅底色与内侧细线，不再叠加向外扩张的黑框；键盘焦点限制在卡片内部。
- 取消分析与 Agent 批注的三条数量上限；标题区每组显示三个，超过三个时出现左右切换按钮，点击画板编号自动切到相应标题。数量由实际问题决定，不增加默认模型输出预算；仍保留响应大小和存储保护。
- 批注允许澄清无标签区域、提出有依据的不确定猜测；含义清楚且没有值得讨论的点时，独立分析可以返回零条建议。避免复述已知布局或凑数量，不把“画得完整”当作“无需讨论”。
- 每条未忽略的批注都有画布编号：元素批注贴近目标，全局批注放在角落，视野外目标保留边缘入口并支持点击定位。选中编号实色、其他编号浅色；已删除目标保留失效入口，不允许继续讨论或修改。
- 关闭重开恢复同一浏览器、同一会话的缩放与平移。视角与草图数据分离，不改变 revision、不触发视觉缓存刷新；本机存储不可用时安全回退默认视角。
- README 加入 MIT → DSH → DeepWiki 徽章。

保持原有会话隔离、focus、CAS、用户预览确认、原生撤销、自动保存和输入草稿保留。没有新增模型服务或后台 AI 请求，也没有升级固定依赖。

附件回收、同步断线需手动恢复、上游无效工具参数及模型误读等已知边界仍保留。零建议支持与提示调整不能保证每次模型判断都正确。安装包与正式发布状态以 GitHub Releases 为准。
