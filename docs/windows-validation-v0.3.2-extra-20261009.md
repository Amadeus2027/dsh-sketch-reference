## 新增非模型证据及局限

**精确升级：** 旧版原生 UI 生成矩形和中文。两类状态及 pending 提议用真实 0.3.1 repository 生成，全部标“迁移夹具，不是模型输出”。升级前后及 UI 打开后三个存储文件哈希相同。原资料已备份，后续才将该隔离草稿替换为可丢弃性能场景。

**确认保护：** 测试代理 gzip 处理错误使宿主提交后响应丢失，原生 UI 显示结果未确认与重试；重启代理同候选重试后 revision/mutationId/sceneDigest 相同，矩形只下移一次。这是本地响应丢失，不是官方模型失败。另有双 API 请求同 receipt 证据。最后两个独立原生编辑器 tab 均先预览、再并行点击确认：首矩形 y=0→12、version=51→52，仅一次改变。一个成功；另一个提示重复应用内容不一致/未确认，载入服务器后恢复。两预览随机元数据不完全相同，安全拒绝不应当成“两者都应成功”的失败。

**实际下载：** download 事件超时但文件真实存在，不能以事件缺失否定。最终修改前备份 1850 bytes、两元素与 proposal.before 精确一致；对应 PNG 6914 bytes 已打开。250 元素三次重开/不同窗口导出都是 1174×984、102284 bytes，SHA256 `776b769cb7b02208fb80d04fce360c7661009a44878f2ae1e12f2a87aa25dbee`，已打开检查。

**重点/主题：** 原生绑定重点 PNG 244×154/5623 bytes 已查看，排除独立中文；切换重点数 1，清除后无重点。标记平移 (80,30) 同量移动，原生 Control+minus 到 90% 后定位正确。真实两个锚点在 1280×720/600×800 仍贴对应角点。窄窗口工具栏折叠，场景可平移。主题恢复 FollowSystem，所有 viewport override 复位，隔离插件重新启用；未改主 profile 主题。

收尾再看 Edge 默认 921×872，发现宿主 frame 的水平 scrollLeft=84，centerCol/shell/iframe 的 x=-28、宽865，导致画板左侧标题被裁切。页面刷新后重新开板仍复现；已保存实际截图与只读 DOM 边界，未用脚本强行改滚动或样式掩盖。尚不能判断是插件壳层还是宿主焦点/滚动布局导致，D03 按观察结果标失败；不能将主题或窄窗口单项通过扩写为显示适配全通过。

**性能：** 有效样本首矩形 x=0→50，验证真实 50 次移动，另有 50 次平移。约 5862ms 自动化区间，1050 个 rAF 间隔，P50 5.6ms/P95 6.1ms/max 6.5ms，观察到 0 个 long-task 事件。IAB 时钟可能来自虚拟/高刷新环境，且含驱动间隔，不换算普遍 FPS 或相对 0.3.0 提速。首次按键落在按钮、未实际移动的样本无效，保留但不计有效证据。

20 次原生开关各约 1195–1328ms（含自动化），均关闭 iframe。browser heap 约 59.3MB 起、93.7MB 后自然降到 60.1MB、末次约 112.96MB。包含宿主/字体/缓存/夹具，没有强制 GC 或插件内存隔离；既不能宣称无泄漏，也不能仅凭增长认定泄漏。P01/P02 缺项仍列 N。
