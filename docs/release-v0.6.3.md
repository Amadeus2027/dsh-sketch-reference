# DSH Sketch Reference 0.6.3

本次集中调整现有界面，依赖仍为 DSH `0.2.1-alpha.1` 与 Excalidraw `0.18.1`。

- 顶部「刷新批注」移入底部「作为参考发送」右侧的「⋯」，更名为「同步批注」。它只读取已有批注，不发起模型请求；成功后显示同步提示，失败时保留原有恢复入口。
- 「隐藏图中标记 / 显示图中标记」位于批注栏最右侧。追问、纠正和修改入口仍在画板内的批注卡片菜单中。
- 「建议模型」使用宿主官方 DeepSeek 模型目录的真实名称，并按宿主提供商名称分组，支持目录中的其他型号，不再写死 Flash 简称。图片能力仍由宿主校验；不支持图片的路线只能用于纯结构分析。非官方提供商仍不纳入这一独立分析入口。
- 「手绘参考板」与保存状态按文字基线对齐。
- 画板菜单的「Find on canvas」显示为「在画布中查找」，继续使用 Excalidraw 原生搜索侧栏与快捷键；帮助、清空画布及背景设置保留。
- 选区重点设置/清除成功提示使用 DSH 原生蓝色；原生聊天里的参考板按钮统一为蓝底白字，未选中、选中和悬停均保持蓝色。保存失败、冲突及其他错误仍保留警告样式。

同步不等于重新分析。需要新的 AI 判断时，使用「AI 分析草图」或在原生聊天中提问。此版本不改变用户确认修改、会话隔离、选区重点和原生撤销机制。
